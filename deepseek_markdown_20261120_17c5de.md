# Game Optimizer PRO — безопасная сборка для Windows 11

## Что делает
- Создаёт резервную копию затрагиваемых пользовательских параметров реестра.
- Включает Windows Game Mode для текущего пользователя.
- Отключает фоновую запись игрового процесса для текущего пользователя.
- Показывает базовый мониторинг CPU/RAM/системного диска и тип диска (HDD/SSD).
- Показывает текущее состояние 4 параметров реестра.
- Позволяет откатить любую резервную копию, а не только последнюю.
- Ведёт лог в `%LOCALAPPDATA%\GameOptimizerPRO\app.log`.

## Что намеренно НЕ делает
Не отключает Defender, Firewall, службы Windows, файл подкачки, системные таймеры, обновления, UAC и визуальные эффекты. Не разгоняет CPU/GPU и не меняет напряжения. Не обещает гарантированный прирост FPS.

## EXE без установки Python на игровом ПК
Проект содержит GitHub Actions workflow. Загрузите ZIP в новый GitHub-репозиторий, затем откройте Actions → Build Windows EXE → Run workflow. После успешной сборки скачайте artifact `GameOptimizerPRO-Windows` из запуска workflow. На ПК, где запускается готовый EXE, Python не нужен.

Альтернатива: на Windows с установленным Python запустить `build_windows.bat`; EXE появится в `dist`.

## Важно
- Это безопасный базовый профиль, а не универсальный FPS-ускоритель.
- Перед применением программа спросит подтверждение и сохранит копию.
- Откат восстанавливает значения из выбранного бэкапа; использованный бэкап помечается и не предлагается повторно.
- Перед обновлением Windows/драйверов и изменением BIOS создавайте отдельные точки восстановления средствами Windows.
- Игровые графические параметры меняются вручную в настройках каждой игры.

## Профиль GTA V MAX FPS
В интерфейсе доступна отдельная карточка рекомендаций GTA V для i5-12400F + RTX 3060 Ti и 1080p. Она показывает безопасные настройки графики, Windows, NVIDIA, HDD и RAM. Профиль не применяет неизвестные реестровые твики из видео автоматически.
